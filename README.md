# 🧰 Boîte à outils JavaScript - 10 fonctions utilitaires



## 📌 Description
Ce projet est un mini-site de documentation interactive présentant 10 fonctions JavaScript utilitaires. Chaque fonction est expliquée, documentée et surtout exécutée en temps réel avec des exemples concrets. Contrairement à une simple documentation statique, ce site affiche les résultats réellement calculés par le JavaScript, permettant aux visiteurs de voir immédiatement le comportement de chaque fonction. Ce projet a été réalisé dans le cadre de la Phase 2 du parcours Développeur Full Stack de l'Akieni Academy, spécifiquement pour la Semaine 7 (niveau Avancé), et constitue le livrable officiel de la semaine. L'objectif était de maîtriser les fonctions JavaScript sous toutes leurs formes (déclaration, expression, arrow functions), tout en réactivant les compétences HTML et CSS acquises lors du Module 1.

## 🎯 Objectifs du projet
Ce projet a été conçu pour développer et valider les compétences suivantes : création de fonctions sous différents styles (déclaration, expression, arrow functions), manipulation des paramètres et des valeurs de retour, compréhension de la portée des variables, logique algorithmique à travers des problèmes classiques (pair/impair, factorielle, nombres premiers, suite de Fibonacci, palindrome, etc.), et génération dynamique de contenu HTML à partir de JavaScript en utilisant des gabarits littéraux. Il s'agissait également de créer un fichier de démonstration exécutant chaque fonction et affichant ses résultats dans la page, tout en respectant la règle de la Semaine 7 qui impose l'utilisation unique de la fonction `afficher()` avec `document.querySelector("#sortie")` pour le rendu visuel, sans manipulation lourde du DOM.

## 🛠️ Technologies utilisées
**HTML5** : Structure sémantique avec les balises header, main, section, nav, footer. **CSS3** : Variables CSS pour la gestion centralisée des couleurs, mise en page avec CSS Grid pour le layout à 2 colonnes, position sticky pour le sommaire latéral, Flexbox pour l'alignement des éléments, animations CSS avec @keyframes, design responsive mobile-first testé de 375px à 1440px, et respect des préférences d'accessibilité avec prefers-reduced-motion. **JavaScript (ES6+)** : Fonctions sous trois styles différents (déclaration, expression, arrow functions), boucles for, conditions if/else, opérateur modulo, méthodes de manipulation de chaînes et de tableaux, template literals pour la génération HTML, et utilisation de JSON.stringify pour l'affichage des tableaux.

## Fonctionnalités
Le site propose 10 fonctions utilitaires complètes avec leur documentation et leurs exemples : **estPair(n)** vérifie si un nombre est pair en utilisant l'opérateur modulo ; **maxDeDeux(a, b)** retourne le plus grand de deux nombres via une condition if/else ; **convertirTemperature(c)** convertit les degrés Celsius en Fahrenheit avec une expression de fonction ; **calculerTVA(prix, taux)** calcule le prix TTC à partir du prix HT et du taux de TVA ; **inverserChaine(texte)** inverse une chaîne de caractères avec une boucle for décroissante ; **compterVoyelles(texte)** compte les voyelles dans une chaîne avec une boucle et la méthode includes ; **estPalindrome(texte)** vérifie si une chaîne est un palindrome en la comparant à son inverse ; **factorielle(n)** calcule la factorielle avec une boucle for ; **estPremier(n)** vérifie si un nombre est premier avec une optimisation utilisant Math.sqrt ; **genererFibonacci(n)** génère les n premiers nombres de la suite de Fibonacci. Chaque fonction est exécutée en temps réel avec plusieurs exemples de test, et les résultats sont affichés directement dans la page, démontrant ainsi le fonctionnement concret de chaque fonction.

## 📂 Structure du projet
Le projet suit une arborescence stricte avec quatre fichiers principaux à la racine. **index.html** contient la structure sémantique du site : un header avec le titre et le sous-titre, un main avec un sommaire latéral (nav) contenant les liens d'ancrage vers chaque fonction, un conteneur principal avec l'id "sortie" où le JavaScript injecte le contenu, et un footer. **style.css** regroupe toutes les mises en forme avec des variables CSS pour les couleurs, le layout Grid, le sticky positioning, les badges colorés, les blocs de code sur fond sombre, et le responsive design. **utils.js** contient les 10 fonctions utilitaires, chacune étant commentée avec JSDoc indiquant son rôle, ses paramètres et sa valeur de retour. **script.js** assure la démonstration avec la fonction `afficher()` pour le rendu, la fonction `afficherDemoFonction()` qui génère le HTML de chaque section, et l'appel de toutes les fonctions avec des exemples variés. **README.md** fournit la documentation complète du projet.

## ⚙️ Installation et utilisation
Pour utiliser ce projet, commence par cloner le repository GitHub sur ta machine locale avec la commande `git clone https://github.com/thomas-issoko/boite-a-outils-10-fonctions.git`. Ensuite, navigue dans le dossier du projet avec `cd boite-a-outils-10-fonctions`. Aucune dépendance ni installation supplémentaire n'est nécessaire car le projet utilise uniquement du HTML, CSS et JavaScript pur. Ouvre simplement le fichier `index.html` dans ton navigateur préféré (double-clic sur le fichier ou glisse-le dans une fenêtre de navigateur). La page se charge automatiquement et affiche le mini-site de documentation avec toutes les fonctions et leurs résultats. Pour tester les fonctions individuellement, tu peux ouvrir la console du navigateur (F12 ou clic droit → Inspecter → onglet Console) et appeler n'importe quelle fonction manuellement, par exemple `estPair(4)` ou `genererFibonacci(10)`. Le site est entièrement responsive et s'adapte à toutes les tailles d'écran, du mobile (375px) au grand écran (1440px).

## 🚀 Commandes utiles
Les commandes Git suivantes ont été utilisées pour la gestion de version : `git init` pour initialiser le repository local, `git add .` pour ajouter tous les fichiers au staging, `git commit -m "message clair"` pour valider les changements avec un message descriptif, `git remote add origin https://github.com/thomas-issoko/boite-a-outils-10-fonctions.git` pour lier le repository local au dépôt distant, et `git push -u origin main` pour pousser le code sur GitHub. Pour le déploiement sur GitHub Pages, il faut activer l'option dans les paramètres du repository (Settings → Pages → choisir la branche main comme source) et l'URL générée sera accessible publiquement. Aucune commande npm ou autre gestionnaire de paquets n'est nécessaire car le projet utilise uniquement des technologies front-end standards.

## 👀 Aperçu
Le mini-site de documentation présente un design épuré et professionnel avec une mise en page en deux colonnes sur desktop. La colonne de gauche contient un sommaire sticky qui reste visible lors du défilement, listant les 10 fonctions avec des liens d'ancrage permettant une navigation rapide. La colonne de droite affiche les sections de chaque fonction, chacune avec son nom en police monospace, un badge coloré indiquant sa catégorie (nombres en bleu, chaînes en violet, conversion en vert), une description claire, la signature de la fonction encadrée, et des exemples d'appel dans des blocs de code sur fond sombre avec les résultats réellement calculés affichés en commentaire. Les sections apparaissent avec une animation de fondu et de translation vers le haut, légèrement décalée pour créer un effet fluide. Sur mobile, le sommaire passe en haut de page et les sections s'affichent en une seule colonne. Les couleurs sont gérées via des variables CSS pour une maintenance facile. L'ensemble est accessible avec des focus visibles pour la navigation au clavier et le respect des préférences de réduction de mouvement.

## 🔧 Améliorations possibles
Plusieurs améliorations pourraient enrichir ce projet. On pourrait ajouter un thème sombre/clair avec un bouton de basculement pour offrir une expérience utilisateur plus personnalisée. Une barre de recherche permettrait de filtrer les fonctions par nom ou par catégorie pour une navigation plus rapide. On pourrait également ajouter des tests unitaires automatisés avec Jest ou Mocha pour valider le bon fonctionnement de chaque fonction. L'intégration d'un éditeur de code interactif permettrait aux utilisateurs de modifier les exemples et de voir les résultats en temps réel. Enfin, on pourrait étendre la bibliothèque à 20 ou 30 fonctions et ajouter un système de catégorisation plus avancé avec des tags multiples, ainsi qu'une fonctionnalité d'exportation des fonctions en format JSON ou en module NPM pour une réutilisation dans d'autres projets.
